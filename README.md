# Python Practice Projects

This repository contains a collection of beginner-level Python projects created to practice and strengthen fundamental Python programming concepts.

The projects focus on writing simple, functional programs using user input, functions, lists, dictionaries, conditional statements, loops, and basic calculations.

## Projects

### 1. Student Grade Calculator

A simple program that takes a student's name and marks for three subjects and calculates:

* Total marks
* Average marks
* Grade

#### Grading System

| Average Marks | Grade          |
| ------------- | -------------- |
| 80–100        | A+             |
| 70–79         | A              |
| 60–69         | B              |
| 50–59         | C              |
| 0–49          | F              |
| Outside 0–100 | No Grade Found |

---

### 2. Simple Shopping Cart

A simple shopping cart program that takes a customer's name and the names and prices of three products.

The program calculates:

* Subtotal
* Discount
* Final total

#### Discount System

| Subtotal      |    Discount |
| ------------- | ----------: |
| 5000 or above |         20% |
| 3000–4999     |         10% |
| Below 3000    | No discount |
